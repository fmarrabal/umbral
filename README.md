# Umbral-C

Laboratorio de control cognitivo medible. No es una persona ni una consciencia.

```
percepto → predicción → discrepancia → hipótesis → acto autorizado → revisión
```

- Live: https://umbral-c-kurrux.vercel.app
- Banco: https://umbral-c-kurrux.vercel.app/banco.html
- Código: este repo (`fmarrabal/umbral`)

## Qué hay aquí

| archivo | qué es |
|---|---|
| `index.html` | ciclo en el navegador: SituationModel, hipótesis que mueren, compromiso estructural |
| `banco.html` | mismas consignas contra 8 políticas (termostato, frame, ReAct, Bayes MAP, GWT, n-grama, greedy, helper) |
| `vercel.json` | sitio estático |

El cubo 16³ (Chladni) es workspace de la hipótesis viva. No decide el permiso.

## Tour

1. `hazlo mejor` abre `falta_criterio` y predice una métrica.
2. `el viernes` mata esa hipótesis. No rellena una fecha. Sigue pidiendo criterio.
3. `NPS > 50` cierra y escribe un compromiso estructural.
4. `déjalo fino` usa el compromiso sin la palabra «mejor».
5. `barato y lujo` es contradicción. Negar una punta cierra.
